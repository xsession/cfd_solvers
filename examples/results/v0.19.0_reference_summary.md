## Re-run and compare

```bash
python3 examples/run_benchmarks.py --build-dir build --output examples/results/my_machine.json --repeat 3
python3 examples/compare_benchmarks.py examples/results/v0.19.0_reference.json examples/results/my_machine.json --fail-on-workload-change
```

The comparison tool reports median runtime, speedup and percentage runtime change. `CHANGED` means the problem size/step count or numerical checksum differs, so the timing is not an apples-to-apples performance comparison.
